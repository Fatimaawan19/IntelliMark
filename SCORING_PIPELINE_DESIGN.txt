                          PART 1: SCORING PRINCIPLES
================================================================================

PRINCIPLE 1: TRANSPARENCY
─────────────────────────────────────────────────────────────────────────────
Every deduction must be explained:
✓ Why deduction was applied
✓ How much was deducted (percentage and points)
✓ Remaining score after deduction
✓ Evidence (matching sources, plagiarism percentage)

PRINCIPLE 2: FAIRNESS
─────────────────────────────────────────────────────────────────────────────
Penalty must match severity:
✓ Low plagiarism (0-20%): No penalty (probably citations)
✓ Medium plagiarism (20-60%): Small-medium penalty
✓ High plagiarism (60-100%): Large penalty
✓ Extreme cases (>80%): Flag for teacher review

PRINCIPLE 3: CONSISTENCY
─────────────────────────────────────────────────────────────────────────────
Same input always produces same output:
✓ Deterministic calculation (no randomness)
✓ Cached results (don't recalculate)
✓ Clear formula (auditable)

PRINCIPLE 4: LOGICAL COHERENCE
─────────────────────────────────────────────────────────────────────────────
No contradictions:
✗ DO NOT say: "72.5% plagiarism found" AND "no similar submissions"
✓ DO say: "72.5% plagiarism | Top match: 85.3% (Ahmad Hassan)"
✗ DO NOT apply 43% penalty with 0 matches found
✓ DO apply: 40-45% penalty BECAUSE 72.5% plagiarism with 5 matches

STEP 1: COMBINE PLAGIARISM SCORES
──────────────────────────────────────────────────────────────────────────────
Formula:
  overallPlagiarismScore = (internal × 0.6) + (external × 0.4)

Example:
  internal = 72.5%
  external = 0%
  overall = (72.5 × 0.6) + (0 × 0.4) = 43.5 + 0 = 43.5%

Why this weighting?
  - 60% internal: Direct student-to-student copying is more severe
  - 40% external: AI usage is policy violation but different category
  - Total: 100% (normalized)

Code:
```javascript
const overallPlagiarismScore = Math.round(
  (internalScore * 0.6) + (externalScore * 0.4)
);
```

STEP 2: DETERMINE PENALTY BAND
──────────────────────────────────────────────────────────────────────────────
Based on overall plagiarism score:

┌─────────────────────────────────────────────────────────────────────────┐
│                    PLAGIARISM PENALTY BANDS                             │
├────────────────┬──────────────┬──────────────┬──────────────────────────┤
│ Plagiarism %   │ Penalty %    │ Action       │ Justification            │
├────────────────┼──────────────┼──────────────┼──────────────────────────┤
│ 0–20%          │ 0%           │ Approve      │ Normal citations/overlap │
│ 20–40%         │ 10%          │ Warn         │ Some concerning overlap  │
│ 40–60%         │ 20%          │ Penalize     │ Significant copying      │
│ 60–80%         │ 45%          │ Major impact │ Extensive plagiarism     │
│ 80–100%        │ 70%          │ Flag review  │ Almost entirely plagiarized│
└────────────────┴──────────────┴──────────────┴──────────────────────────┘

Decision Logic:
```javascript
function getPenaltyBand(plagiarismScore) {
  if (plagiarismScore >= 80) {
    return {
      band: "EXTREME",
      penaltyPercent: 70,
      action: "FLAG_FOR_REVIEW",
      message: "Submission is almost entirely plagiarized. Requires teacher review."
    };
  }
  if (plagiarismScore >= 60) {
    return {
      band: "HIGH",
      penaltyPercent: 45,
      action: "MAJOR_PENALTY",
      message: "Extensive plagiarism detected. Significant grade deduction applied."
    };
  }
  if (plagiarismScore >= 40) {
    return {
      band: "MEDIUM",
      penaltyPercent: 20,
      action: "PENALIZE",
      message: "Significant plagiarism detected. Grade penalty applied."
    };
  }
  if (plagiarismScore >= 20) {
    return {
      band: "LOW",
      penaltyPercent: 10,
      action: "WARN",
      message: "Some plagiarism detected. Minor grade penalty applied."
    };
  }
  return {
    band: "NONE",
    penaltyPercent: 0,
    action: "APPROVE",
    message: "No significant plagiarism detected."
  };
}
```

STEP 3: APPLY PENALTY TO AI SCORE
──────────────────────────────────────────────────────────────────────────────
Formula:
  adjustedScore = aiScore × (1 - (penaltyPercent / 100))

Example 1: Low plagiarism
  aiScore = 8.5, plagiarism = 15%, penalty = 0%
  adjustedScore = 8.5 × (1 - 0/100) = 8.5 × 1.0 = 8.5/10 ✓

Example 2: Medium plagiarism
  aiScore = 8.5, plagiarism = 45%, penalty = 20%
  adjustedScore = 8.5 × (1 - 20/100) = 8.5 × 0.8 = 6.8/10 ✓

Example 3: High plagiarism
  aiScore = 8.5, plagiarism = 72.5%, penalty = 45%
  adjustedScore = 8.5 × (1 - 45/100) = 8.5 × 0.55 = 4.675 ≈ 4.7/10 ✓

Example 4: Extreme plagiarism
  aiScore = 8.5, plagiarism = 95%, penalty = 70%
  adjustedScore = 8.5 × (1 - 70/100) = 8.5 × 0.3 = 2.55 ≈ 2.6/10 ✓

Code:
```javascript
const adjustedScore = aiScore * (1 - (penaltyPercent / 100));
const finalScore = Math.round(adjustedScore * 10) / 10;  // One decimal place
```

STEP 4: CALCULATE FINAL SCORE (OUT OF MAX)
──────────────────────────────────────────────────────────────────────────────
Formula:
  finalScore = (adjustedScore / 10) × maxScore

If maxScore = 10:
  finalScore = adjustedScore (already in 0-10 range)

If maxScore = 100:
  finalScore = adjustedScore × 10

Code:
```javascript
const scoreRatio = adjustedScore / 10;  // Convert to 0-1 ratio
const finalScore = scoreRatio * maxScore;
```

const Submission = require("../models/Submission");
const SubmissionRaw = require("../models/SubmissionRaw");
const PlagiarismReport = require("../models/PlagiarismReport");

/**
 * CONSISTENT SCORING PIPELINE
 * Calculates final grade with transparent plagiarism penalty
 */

// ═══════════════════════════════════════════════════════════════════════════
// 1. PLAGIARISM BANDS (CONFIGURABLE)
// ═══════════════════════════════════════════════════════════════════════════

const PLAGIARISM_BANDS = {
  EXTREME: {
    range: [80, 100],
    penalty: 70,
    action: "FLAG_FOR_REVIEW",
    risk: "EXTREME",
    message: "Submission is almost entirely plagiarized."
  },
  HIGH: {
    range: [60, 80),
    penalty: 45,
    action: "MAJOR_PENALTY",
    risk: "HIGH",
    message: "Extensive plagiarism detected."
  },
  MEDIUM: {
    range: [40, 60),
    penalty: 20,
    action: "PENALIZE",
    risk: "MEDIUM",
    message: "Significant plagiarism detected."
  },
  LOW: {
    range: [20, 40),
    penalty: 10,
    action: "WARN",
    risk: "MEDIUM",
    message: "Some plagiarism detected."
  },
  NONE: {
    range: [0, 20),
    penalty: 0,
    action: "APPROVE",
    risk: "LOW",
    message: "No significant plagiarism detected."
  }
};

// ═══════════════════════════════════════════════════════════════════════════
// 2. GET PLAGIARISM BAND
// ═══════════════════════════════════════════════════════════════════════════

function getPlagiarismBand(plagiarismScore) {
  for (const [bandName, bandConfig] of Object.entries(PLAGIARISM_BANDS)) {
    const [min, max] = bandConfig.range;
    if (plagiarismScore >= min && plagiarismScore < max) {
      return {
        band: bandName,
        ...bandConfig
      };
    }
  }
  // Default: EXTREME (if >= 100)
  return {
    band: "EXTREME",
    ...PLAGIARISM_BANDS.EXTREME
  };
}

// ═══════════════════════════════════════════════════════════════════════════
// 3. CALCULATE CONSISTENT SCORE
// ═══════════════════════════════════════════════════════════════════════════

async function calculateConsistentScore(submission) {
  const submissionId = submission._id.toString();

  try {
    console.log(`[SCORING] Calculating score for ${submissionId}`);

    // Get AI grade
    const aiScore = Number(submission.grade || 0);
    const maxScore = Number(submission.maxGrade || 10);

    if (!aiScore || aiScore < 0) {
      throw new Error("Invalid AI score");
    }

    // Get plagiarism report
    const plagiarismReport = await PlagiarismReport.findOne({
      submissionId
    }).lean();

    if (!plagiarismReport) {
      throw new Error("Plagiarism report not found");
    }

    // STEP 1: Get component scores
    const internalScore = Number(plagiarismReport.internalScore || 0);
    const externalScore = Number(plagiarismReport.aiScore || 0);

    // STEP 2: Calculate overall plagiarism (60% internal + 40% external)
    const overallPlagiarism = Math.round(
      (internalScore * 0.6) + (externalScore * 0.4)
    );

    console.log(`[SCORING] Internal: ${internalScore}%, External: ${externalScore}%`);
    console.log(`[SCORING] Overall plagiarism: ${overallPlagiarism}%`);

    // STEP 3: Get penalty band
    const penaltyBand = getPlagiarismBand(overallPlagiarism);
    const penaltyPercent = penaltyBand.penalty;

    console.log(`[SCORING] Band: ${penaltyBand.band}, Penalty: ${penaltyPercent}%`);

    // STEP 4: Apply penalty
    const scoreMultiplier = 1 - (penaltyPercent / 100);
    const adjustedScore = aiScore * scoreMultiplier;
    const finalScore = Math.round(adjustedScore * 10) / 10;

    // STEP 5: Scale to max score if needed
    const scaledScore = (finalScore / 10) * maxScore;
    const finalScaledScore = Math.round(scaledScore * 10) / 10;

    // STEP 6: Calculate percentage
    const finalPercentage = (finalScaledScore / maxScore) * 100;

    console.log(`[SCORING] Final: ${finalScaledScore}/${maxScore} (${finalPercentage.toFixed(1)}%)`);

    // ═════════════════════════════════════════════════════════════════════
    // BUILD RESPONSE
    // ═════════════════════════════════════════════════════════════════════

    const response = {
      // Submission info
      submission: {
        submissionId,
        studentName: submission.studentName,
        studentId: submission.studentId,
        assessmentTitle: submission.assessmentTitle,
        assessmentId: submission.assessmentId
      },

      // Grading info
      grading: {
        aiScore,
        maxScore,
        status: "graded",
        gradedAt: submission.gradedAt || new Date(),
        provider: submission.llmProvider || "unknown"
      },

      // Plagiarism breakdown
      plagiarism: {
        overallScore: overallPlagiarism,
        internal: {
          score: internalScore,
          matchCount: plagiarismReport.topMatches?.length || 0,
          topMatches: plagiarismReport.topMatches?.slice(0, 5) || []
        },
        external: {
          score: externalScore,
          provider: plagiarismReport.provider || "unknown",
          sources: plagiarismReport.sources?.slice(0, 3) || []
        }
      },

      // Penalty application
      penalty: {
        plagiarismScore: overallPlagiarism,
        band: penaltyBand.band,
        penaltyPercent,
        penaltyPoints: Math.round((aiScore - adjustedScore) * 10) / 10,
        justification: penaltyBand.message
      },

      // Final score
      finalScore: {
        beforePenalty: aiScore,
        penalty: -Math.round((aiScore - adjustedScore) * 10) / 10,
        afterPenalty: adjustedScore,
        maxScore,
        percentage: Math.round(finalPercentage * 10) / 10,
        letterGrade: getLetterGrade(finalPercentage)
      },

      // Transparency
      transparency: {
        scoreBreakdown: {
          aiGrade: {
            value: aiScore,
            explanation: `AI evaluated your answer and awarded ${aiScore} out of ${maxScore}.`
          },
          plagiarismDetection: {
            internal: {
              value: internalScore,
              explanation: `${internalScore}% of your text matched other students' submissions (${plagiarismReport.topMatches?.length || 0} similar submissions detected via FAISS).`
            },
            external: {
              value: externalScore,
              explanation: `${externalScore}% of your text appears to be AI-generated (via ${plagiarismReport.provider || 'detection service'}).`
            },
            combined: {
              value: overallPlagiarism,
              formula: `(${internalScore} × 0.6) + (${externalScore} × 0.4) = ${overallPlagiarism}%`,
              explanation: "Overall plagiarism score combining internal (60% weight) and external (40% weight) detection."
            }
          },
          penaltyApplication: {
            band: `${penaltyBand.band} (${penaltyBand.range[0]}-${penaltyBand.range[1]}%)`,
            reason: `Your plagiarism score (${overallPlagiarism}%) falls in the ${penaltyBand.band} range.`,
            penaltyRate: `${penaltyPercent}% of grade deducted`,
            calculation: `${aiScore} × (1 - ${penaltyPercent}/100) = ${aiScore} × ${scoreMultiplier} = ${adjustedScore}`
          }
        },

        studentFeedback: buildStudentFeedback(aiScore, overallPlagiarism, penaltyBand),
        teacherNotes: {
          flaggedForReview: penaltyBand.band === "EXTREME" || penaltyBand.band === "HIGH",
          suggestedAction: penaltyBand.action,
          riskLevel: penaltyBand.risk,
          recommendation: buildTeacherRecommendation(penaltyBand)
        }
      }
    };

    return response;

  } catch (err) {
    console.error(`[SCORING] Error: ${err.message}`);
    throw err;
  }
}

// 4. HELPER FUNCTIONS
// ═══════════════════════════════════════════════════════════════════════════

function getLetterGrade(percentage) {
  if (percentage >= 90) return "A";
  if (percentage >= 80) return "B";
  if (percentage >= 70) return "C";
  if (percentage >= 60) return "D";
  return "F";
}

function buildStudentFeedback(aiScore, plagiarismScore, penaltyBand) {
  if (penaltyBand.penalty === 0) {
    return `Excellent work! Your answer demonstrates strong understanding (AI score: ${aiScore}/10) and no significant plagiarism detected.`;
  }
  if (penaltyBand.penalty <= 10) {
    return `Good work overall (AI score: ${aiScore}/10), but there is some overlap with other submissions. Please ensure proper attribution. A minor penalty has been applied.`;
  }
  if (penaltyBand.penalty <= 20) {
    return `Your answer shows understanding (AI score: ${aiScore}/10), but there is significant overlap with other submissions. A ${penaltyBand.penalty}% penalty has been applied. Review the detected matches and improve citations.`;
  }
  if (penaltyBand.penalty <= 45) {
    return `While your answer has some good points (AI score: ${aiScore}/10), there is extensive plagiarism (${plagiarismScore}%). A major penalty has been applied. This requires careful review.`;
  }
  return `Your submission has very high plagiarism levels (${plagiarismScore}%). This submission has been flagged for teacher review.`;
}

function buildTeacherRecommendation(penaltyBand) {
  const recommendations = {
    EXTREME: "Submission is almost entirely plagiarized. Recommend academic integrity review and student conference.",
    HIGH: "Significant plagiarism detected. Grade penalty applied. Consider warning student.",
    MEDIUM: "Grade is fair given plagiarism level. Acceptable with penalty.",
    LOW: "Minor plagiarism. Grade is acceptable with light penalty.",
    NONE: "No significant plagiarism. Grade is appropriate."
  };
  return recommendations[penaltyBand.band] || "Review required.";
}

#!/usr/bin/env node
require("dotenv").config({ path: ".env" });
const mongoose = require("mongoose");
const Submission = require("../models/Submission");
const PlagiarismReport = require("../models/PlagiarismReport");
const { calculateConsistentScore } = require("../utils/consistentScoringService");

const MONGO_URI = process.env.MONGO_URI;

console.log("\n🔧 Fix All Submission Scores - Consistent Scoring Pipeline");
console.log("════════════════════════════════════════════════════════════\n");

(async () => {
  try {
    await mongoose.connect(MONGO_URI);
    console.log("✅ Connected to MongoDB\n");

    // Find all graded submissions
    const submissions = await Submission.find({
      status: "graded",
      grade: { $exists: true, $ne: null }
    }).sort({ gradedAt: -1 });

    console.log(`📊 Found ${submissions.length} graded submissions\n`);

    if (submissions.length === 0) {
      console.log("✅ No graded submissions to fix\n");
      process.exit(0);
    }

    let fixedCount = 0;
    let errorCount = 0;
    const changes = [];

    for (let i = 0; i < submissions.length; i++) {
      const sub = submissions[i];
      const progressBar = `[${i + 1}/${submissions.length}]`;

      try {
        // Check if plagiarism report exists
        const plagiarismReport = await PlagiarismReport.findOne({
          submissionId: sub._id
        });

        if (!plagiarismReport) {
          console.log(`${progressBar} ⚠️  ${sub.studentName}: No plagiarism report found`);
          errorCount++;
          continue;
        }

        // Calculate new consistent score
        const scoreResult = await calculateConsistentScore(sub);

        // Get old values
        const oldFinalScore = sub.grade;
        const newFinalScore = scoreResult.finalScore.afterPenalty;
        const newPercentage = scoreResult.finalScore.percentage;

        // Check if different
        const isDifferent = Math.abs(oldFinalScore - newFinalScore) > 0.1;

        if (isDifferent) {
          // Update submission
          await Submission.updateOne(
            { _id: sub._id },
            {
              $set: {
                grade: newFinalScore,
                gradedAt: new Date(),
                scoringMethod: "consistent",
                scoreBreakdown: {
                  aiScore: scoreResult.grading.aiScore,
                  plagiarismScore: scoreResult.plagiarism.overallScore,
                  penaltyPercent: scoreResult.penalty.penaltyPercent,
                  finalScore: newFinalScore
                }
              }
            }
          );

          changes.push({
            studentName: sub.studentName,
            old: oldFinalScore,
            new: newFinalScore,
            percentageChange: ((newFinalScore - oldFinalScore) / oldFinalScore * 100).toFixed(1),
            plagiarism: scoreResult.plagiarism.overallScore,
            penalty: scoreResult.penalty.penaltyPercent
          });

          console.log(`${progressBar} ✏️  ${sub.studentName}: ${oldFinalScore} → ${newFinalScore} (${newPercentage.toFixed(1)}%)`);
          fixedCount++;
        } else {
          console.log(`${progressBar} ✅ ${sub.studentName}: No change needed (${newFinalScore})`);
        }
      } catch (err) {
        console.error(`${progressBar} ❌ Error: ${err.message}`);
        errorCount++;
      }
    }

    console.log(`\n${"═".repeat(80)}`);
    console.log("SUMMARY");
