================================================================================
                          KEY FORMULAS
================================================================================

1. OVERALL PLAGIARISM SCORE
   overallPlagiarism = (internalScore × 0.6) + (externalScore × 0.4)

   Example: (72.5 × 0.6) + (0 × 0.4) = 43.5%

2. PENALTY APPLICATION
   adjustedScore = aiScore × (1 - (penaltyPercent / 100))

   Example: 8.5 × (1 - 20/100) = 8.5 × 0.8 = 6.8

3. FINAL PERCENTAGE
   finalPercentage = (finalScore / maxScore) × 100

   Example: (6.8 / 10) × 100 = 68%

4. LETTER GRADE
   A: 90-100%
   B: 80-89%
   C: 70-79%
   D: 60-69%
   F: <60%

================================================================================
                      DESIGN PRINCIPLES
================================================================================

1. TRANSPARENCY
   ✓ Every deduction is explained with formulas
   ✓ Students see exactly why they lost points
   ✓ Teachers see detailed audit trail
   ✓ Formulas are visible in UI

2. FAIRNESS
   ✓ Proportional penalties (not extreme)
   ✓ 0% plagiarism = 0% penalty (fair to honest work)
   ✓ 100% plagiarism = 70% penalty (preserves some points)
   ✓ Clear band boundaries (no ambiguity)

3. CONSISTENCY
   ✓ Deterministic calculation (same input = same output)
   ✓ Cached results ensure stability
   ✓ Database persistence prevents re-calculation
   ✓ Clear definitions leave no room for interpretation

4. LOGICAL COHERENCE
   ✗ Never: "72.5% plagiarism" AND "no matches found"
   ✓ Always: "43.5% plagiarism" WITH matching students shown
   ✗ Never: Applied penalty without corresponding plagiarism
   ✓ Always: Clear band justification for penalty
