## What ZeroGPT Detection Does

When working with valid credits, ZeroGPT will:

1. **Analyze submission text** for AI-generated patterns
2. **Return AI score** (0-100%)
3. **Flag if GPT-generated** (boolean)
4. **Provide feedback** on detection confidence

### Example Response (when working):
```json
{
  "success": true,
  "data": {
    "fake_percentage": 87,           // 87% AI-generated
    "is_gpt_generated": true,         // Flagged as AI
    "additional_feedback": "High confidence that this content was generated by GPT-4 or similar model"
  }
}
```
